## MiniBill 1.0.9

飞牛微应用体验：宿主语言/深色主题与窗口标题同步；月度余额登记规则调整。

### 界面与体验
- 飞牛微应用：跟随宿主语言；外观为「跟随系统」时跟随宿主深色/浅色主题
- 宿主窗口标题与账本标题同步
- 优化切页流畅度（减少重复宿主标题同步与过长淡入）
- 修复 iPhone 上悬浮返回、流水底栏等控件毛玻璃效果失效

### 月度余额
- 每月 25 日之前仅可登记上个月余额；25 日起可登记当月余额
- 已登记的月度余额支持删除（一并清除该月推算的日常支出系统流水）

### 升级说明
- **飞牛 NAS**：升级 fpk 后即可
- **Docker / 自托管**：升级镜像后即可
- **Windows 打包**：`scripts\build-fpk.cmd 1.0.9 x86|arm|all`
