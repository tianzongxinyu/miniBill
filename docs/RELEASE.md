## MiniBill 1.0.9

飞牛开放 API 接入：宿主语言/深色主题同步、备份目录共享授权与应用设置入口。

### 界面与体验
- 飞牛微应用：跟随宿主语言；外观为「跟随系统」时跟随宿主深色/浅色主题
- 宿主窗口标题与账本标题同步

### 部署
- 管理员可在备份页通过系统选择器授权共享目录作为备份路径（亦可继续用手填/环境变量）
- 备份页可打开飞牛应用设置、文件管理器及最近备份文件
- 需 fnOS `1.2.0401+`、App `1.34.0+`（详见 [docs/deploy.md](docs/deploy.md)）

### 升级说明
- **飞牛 NAS**：升级 fpk 后即可；首次使用共享目录备份时，请由管理员在 **我的 → 备份管理** 中选择目录
- **Docker / 自托管**：无飞牛开放 API；备份仍用 `BACKUP_DIR`，行为与现网一致
- **Windows 打包**：`scripts\build-fpk.cmd 1.0.9 x86|arm|all`
