## MiniBill 1.0.10

飞牛统一网关免密登录（同名账号）；按月周期任务；修复 CSV 追加导入后历史月统计不刷新。

### 新增
- 按月周期任务：设定金额、收支类型、每月第几天（1–28）、标签、联系人与备注；开启后到期自动创建流水，服务停机漏跑会补建
- 个人中心可管理周期任务列表与编辑

### 飞牛
- 桌面入口改为统一网关路径 `/app/minibill`（系统域名下打开，不再依赖直连端口 iframe）
- 已登录 NAS 且存在**同名**轻账单账号时自动签发会话进入；无同名账号仍走账密登录（不自动建号）

### 调整
- 周期任务调度：服务启动时执行一次，之后每天本地凌晨 1:00 再执行
- 自动备份扫描：启动时执行一次，之后自 0:00 起每 5 分钟对齐扫描（是否真正备份仍由用户备份配置决定）

### 修复
- CSV「保留历史」导入后，历史月份 `stat_monthly` 收支汇总从流水全量重算，避免账单页 0 值占位导致统计不更新

### 升级说明
- **飞牛 NAS**：升级 fpk 后即可；入口变为 `/app/minibill`。若需免密，请确保 MiniBill 用户名与 NAS 用户名一致
- **Docker / 自托管**：升级镜像后即可（行为与路径不变，无 NAS 免密）
- **Windows 打包**：`scripts\build-fpk.cmd 1.0.10 x86|arm|all`
