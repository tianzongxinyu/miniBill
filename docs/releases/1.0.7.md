# 轻账单 1.0.7 飞牛商店版本说明

可直接粘贴到飞牛开发者后台「版本说明」：

```

1. 修改或重置密码后，旧登录会话立即失效，账户更安全

6. 搜索与筛选工具栏统一整理，摘要筛选体验更一致

【首页与年报】
7. 首页加载更快：月账单与图表并行请求，图表预加载，热门排行延后加载
8. 热门联系人布局与金额展示优化
9. 年度报告默认展示当年；大额明细可查看联系人 / 标签，并支持一键跳转

【部署与文档】
10. 飞牛安装向导精简（去掉注册开关），重置密码说明更完善
```
