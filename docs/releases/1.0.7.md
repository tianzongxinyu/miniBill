# 轻账单 1.0.7 飞牛商店版本说明

可直接粘贴到飞牛开发者后台「版本说明」：

```
【安全与账号】
1. 修改或重置密码后，旧登录会话立即失效，账户更安全
2. 新增管理员重置密码（含 Docker / 飞牛一键脚本）；登录页提示忘记密码时可联系管理员处理

【检索与管理】
3. 流水检索时隐藏月份选择，并展示全部匹配结果的总支出 / 总收入
4. 流水 / 统计高级检索支持标签「且 / 或」匹配（全部满足 / 任一满足）
5. 联系人支持行内改名与隐藏 / 显示，自动校验空名与重名
6. 标签支持行内改名（系统预设标签除外），自动校验重名
7. 搜索与筛选工具栏统一整理，摘要筛选体验更一致

【首页、统计与年报】
8. 首页热门联系人 / 热门标签可一键跳转流水，并自动带上筛选条件
9. 统计页月 / 年切换改为连体短标签；序列表字号更紧凑
10. 年报联系人 Top5：笔数跟在名称后，下方展示主题色收支进度条（大额断轴）
11. 首页加载更快：月账单与图表并行请求，热门排行延后加载
12. 年度报告默认展示当年；大额明细可查看联系人 / 标签并一键跳转

【部署与文档】
13. 飞牛安装向导精简；重置密码支持自动探测数据目录，部署说明更清晰
14. 同步部署 / API 文档与多语言文案，并补充相关测试用例
```
